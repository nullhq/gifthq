# **GiftHQ** 🎁  

**GiftHQ** is a **Telegram Mini App** where users can buy and send **virtual gifts** using **Stars**.  

### 🎯 **How It Works**  
- The more gifts you **send**, the more **$GIFT** you earn!  
- **Givers get rewarded more than receivers**—it pays to be generous!  
- Earn extra **$GIFT** by **inviting friends** or **completing tasks** in the app.  

### 🏗 **Project Structure**  
📂 **Frontend** → [`gifthqUI`](#) (React / Miniapp UI)  
📂 **Backend** → [`gifthqSERVER`](#) (Node.js / API / Blockchain Integration)  

### 🚀 **Tech Stack**  
- **Frontend**: React, Telegram WebApp SDK  
- **Backend**: Node.js, Express, MongoDB  
- **Blockchain**: TON (Jetton v2)
